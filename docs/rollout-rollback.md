# 切换与回滚

## 当前边界

本次只建立新系统基线，不切换真实用户、不写生产数据库、不迁移旧账。

## 后续切换顺序

1. 冻结旧数据库结构和接口契约。
2. 只读盘点旧数据，保存快照和校验值。
3. 复制到隔离 PostgreSQL，逐表对账。
4. 新系统只读旧数据，与旧页面抽样比对。
5. 影子流量只比较结果，不允许双写资金。
6. 小范围账号灰度写入，每个资金动作只有一个系统负责。
7. 确认无重复、无漏单、无余额差异后扩大范围。

## 立即回滚

当前新项目完全独立。若新系统基线不继续采用：

```bash
docker compose down
```

随后删除或归档 `max-promotion/` 目录即可恢复外层项目原状。旧 PHP、SQLite、快照和验收资料均未被修改。

## 生产切换后回滚

- 停止新系统资金写入口。
- 保存新系统现场、日志和数据库快照。
- 将流量切回旧系统。
- 对切换窗口内新旧两边数据做一次增量核对。
- 不允许直接删除多出的资金流水；通过受控调账单据修正并留痕。
