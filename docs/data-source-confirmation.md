# 旧数据迁移业务确认表

本表必须由业务对方依据实际数据填写并确认。未完成确认前，禁止导入 PostgreSQL、启用真实资金或切换生产环境。

## 一、数据源

| 确认项                          | 对方填写 |
| ------------------------------- | -------- |
| 唯一数据源绝对路径或安全位置    |          |
| 文件 SHA-256                    |          |
| 数据截止时间（北京时间）        |          |
| 数据性质：演示 / 验收 / 生产    |          |
| 是否允许复制到隔离迁移环境      | 是 / 否  |
| 是否允许导入测试 PostgreSQL     | 是 / 否  |
| 是否允许后续导入生产 PostgreSQL | 是 / 否  |

## 二、业务决策

| 编号 | 必须明确的事项                                        | 对方确认结果 |
| ---- | ----------------------------------------------------- | ------------ |
| 1    | 演示资金是否保留；若保留，是否明确标记为不可提现      |              |
| 2    | 一级、二级、三级返佣的比例、基数、结算时机和追溯范围  |              |
| 3    | 旧充值单是迁移为正式充值记录、历史归档，还是排除      |              |
| 4    | 旧 `cancelled` 提现状态对应新系统的取消、拒绝还是关闭 |              |
| 5    | 已自动通过且无审核人的记录是否保留原自动通过说明      |              |
| 6    | 旧账号首次登录采用密码安全升级还是强制重置            |              |
| 7    | 没有实名资料的账号是否统一标记为未认证                |              |

## 三、金额与人员

| 确认项                                                       | 对方填写 |
| ------------------------------------------------------------ | -------- |
| 用户、任务、提交、钱包、流水、充值、提现、审计日志的预期行数 |          |
| 可用余额预期合计（分）                                       |          |
| 冻结余额预期合计（分）                                       |          |
| 迁移负责人                                                   |          |
| 资金对账负责人                                               |          |
| 业务验收负责人                                               |          |

## 四、最终授权

| 确认项                   | 对方填写        |
| ------------------------ | --------------- |
| 是否批准进入隔离导入演练 | 是 / 否         |
| 是否批准真实资金切换     | 是 / 否；默认否 |
| 是否批准生产环境切换     | 是 / 否；默认否 |
| 业务对方姓名或主体       |                 |
| 确认日期                 |                 |
| 书面确认凭据位置或编号   |                 |

## 五、禁止事项

- 不得代替业务对方勾选或补填确认结果。
- 不得把演示库、测试库或验收副本宣称为生产数据。
- 不得把账号、手机号或管理员口头认可宣称为实名认证。
- 不得在确认前补造审核人、资金流水、充值记录或提现状态。
