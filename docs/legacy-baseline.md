## 3. 旧系统能力

- 角色：推广客户（`promoter`）、商户（`merchant`）、管理员（`admin`）。
- 业务闭环：任务发布、随机领取、凭证提交、审核、保证金退还、佣金与上级返单、结束任务退预算。
- 资金：金额按“分”保存；钱包变化和资金流水同事务；资金动作有唯一幂等键。
- 财务辅助：演示充值、提现申请与审核、受控余额调整、钱包流水对账、审计日志。
- 认证：PHP Session（会话登录），新系统不能直接沿用。
- 数据库：本机 SQLite，仅用于开发和自动测试，不是生产数据库。

## 4. 新系统保留与改变

保留：

- 金额以整数“分”保存。
- 钱包变化与业务状态变化同事务提交。
- 资金动作使用唯一幂等键。
- 审核通过才结算商户预算并发放佣金；驳回只退保证金。
- 任务结束前必须清完待提交和待审核记录。
- 管理员调账必须有原因、操作人和资金流水。

改变：

- 商户不再单独提供前端，商户、任务和审核操作统一放进管理员后台。
- 后端改为 NestJS，数据库改为 PostgreSQL，ORM（对象关系映射）改为 Prisma。
- 登录改为短期 JWT（JSON Web Token）+ 数据库哈希刷新令牌，密码改用 Argon2id。
- 旧 PHP/SQLite 保持原样，后续迁移必须另做只读盘点、复制、对账和灰度切换。
