## 安全与运维限制

- 告警 Webhook 默认关闭，尚未向真实接收端发送过消息；生产配置应使用 HTTPS。
- 审计日志自动清理尚未在生产环境启用。启用前必须确认法务、财务和审计要求，完成备份，并在预发布库观察至少一个清理周期。
- 删除的审计日志不能通过业务接口恢复；发生误删时只能从启用前的数据库备份恢复到隔离实例核对。
- 每日备份脚本已在本机实测并加入持续集成配置，但尚未在正式 VPS 配置 Cron（定时任务），也未实际运行 GitHub Actions。
- 备份恢复目前只在同一 PostgreSQL 实例内完成，尚未验证独立服务器、加密备份、WAL（预写日志）归档、异地副本和实际灾难恢复耗时。
- 尚未连接 GitHub 远程仓库；工作流仅完成本地配置检查。
- 尚未执行正式部署、真实资金切换、旧数据迁移或认证权限调整。

## 风险与回滚

- 本轮不修改数据库结构、认证权限、资金业务实现或旧 SQLite 数据。
- 若需要回滚代码，执行 `git revert <本轮提交哈希>`。
- 若生产已启用审计清理，应先设置 `AUDIT_RETENTION_DAYS=0` 并重新部署，再评估是否从备份恢复。
- 本轮两个隔离容器均已停止并删除，未接触正式数据库。
