# 界面设计基线

## 设计目标

受众是推广客户与平台运营人员。界面的首要任务是让人快速看懂“还有多少钱可动、当前该做什么、这笔钱为什么变动”。

## 设计计划

### 色彩

| 名称              | 色值      | 用途               |
| ----------------- | --------- | ------------------ |
| 深海墨绿 `ink`    | `#16343B` | 主文字、深色区域   |
| 雾青 `mist`       | `#EAF1F0` | 页面背景、分区     |
| 纸张白 `paper`    | `#F8FAF7` | 内容底色           |
| 工作绿 `work`     | `#2C756C` | 主操作、正常状态   |
| 风险橙红 `signal` | `#E45D42` | 驳回、风险、异常   |
| 印章铜金 `brass`  | `#C49A3A` | 资金、身份与强调线 |

### 字体

- 标题与资金大数字：`Songti SC`、`Noto Serif CJK SC`，形成台账和票据感。
- 正文与表单：`PingFang SC`、`Noto Sans CJK SC`，保持中文阅读效率。
- 数字使用等宽数字特性，避免金额跳动。

### 布局

桌面端左侧是窄型业务索引，顶部是可支配资金票根，主体用不规则双栏和大面积台账行。推广客户不面对任务卡片挑选，而是一个清晰的随机派单区；管理员在一个连续作业台处理商户、任务和审核，减少跨页面切换。

```text
┌──────────┬────────────────────────────────────────┐
│ 角色/导航 │ 当前身份         可支配金额 ─ 冻结金额 │
├──────────┼─────────────────────┬──────────────────┤
│ 工作台    │ 下一步动作           │ 今日额度/待办     │
│ 推广任务  │                     │                  │
│ 资金流水  │ 任务派单票根          │ 风险提醒/审计摘要 │
│ 提现      │                     │                  │
└──────────┴─────────────────────┴──────────────────┘
```

移动端将左侧导航变成底部标签，金额票根在顶部横向展开，作业区改为单栏。

## 设计原则

- 一次只突出一个主要动作。
- 资金、状态和风险使用结构线表达，不靠装饰图标堆砌。
- 票据缺口、印章状态和连续台账行是唯一记忆点，其余区域保持克制。
- 不使用奶油色配陶土色，不使用所有卡片统一圆角和阴影。
- 键盘焦点始终可见；系统设置“减少动态效果”时关闭过渡动画。

## 自查与修正

初稿容易滑向通用 SaaS 的指标卡集合，因此已去掉“每个指标一张圆角卡”的做法，改为连续的分隔带。另一处修正是不再把商户端做成独立副本；商户资料、发布任务和凭证审核都进入管理员作业台。
