# 主要第三方依赖

本项目使用的主要直接依赖如下。各依赖的完整许可文本以锁定版本随包附带的许可证为准。

| 组件                          | 用途               | 主要许可                     |
| ----------------------------- | ------------------ | ---------------------------- |
| React、React DOM              | Web 界面           | MIT                          |
| Vite                          | 前端构建           | MIT                          |
| TypeScript                    | 类型检查与编译     | Apache-2.0                   |
| Tailwind CSS                  | 界面样式           | MIT                          |
| NestJS                        | 后端框架           | MIT                          |
| Prisma ORM                    | 数据库访问与迁移   | Apache-2.0                   |
| PostgreSQL                    | 数据库             | PostgreSQL License           |
| Argon2                        | 密码哈希           | MIT / Apache-2.0             |
| Swagger / OpenAPI             | 接口文档           | Apache-2.0                   |
| Node.js                       | JavaScript 运行时  | MIT 及随附组件许可           |
| Docker Engine、Docker Compose | 容器运行与编排     | Apache-2.0                   |
| Coolify                       | 可选自托管部署面板 | Apache-2.0                   |
| GitHub                        | 可选代码托管平台   | 专有在线服务，不随本项目开源 |

Docker Desktop 的许可与 Linux Docker Engine 不同，部分商业使用场景需要付费订阅。VPS、域名、对象存储、短信、实名认证和支付通道均属于外部付费或受监管服务，不属于本仓库代码。

正式分发前应使用软件组成分析工具生成完整依赖清单并归档许可证文本。本文件不是法律意见。
